# SM Solver Ultra

基于 React + Vite 的交互式结构力学求解器与可视化，内置多态荷载系统、固端等效节点力（FEF）转换、高清 Canvas 渲染与简洁友好的建模体验。适用于教学演示、概念验证与轻量工程场景。

## 特性

- 多态荷载系统
  - 节点荷载：`Fx`、`Fy`、`M`（逆时针为正）
  - 单元荷载：
    - 均布荷载 `q`
    - 梯形/线性分布荷载 `q1 → q2`
    - 集中力 `P`（支持轴向/垂直方向）
    - 集中弯矩 `M`
  - 等效节点力（FEF）在局部坐标系计算并转换到全局坐标系

- 计算引擎
  - 梁-杆单元 6×6 局部刚度矩阵与方向余弦变换
  - 支座约束（固定端、铰支座、滚动支座 X/Y）通过大数法处理
  - 线性方程求解：带全主元的高斯消元
  - 结果输出：位移向量与每个单元端部内力（`moment`、`shear`、`axial`）

- 可视化与交互
  - 高清 Canvas（按设备像素比渲染），线条与文本更锐利
  - 文本字号固定为像素值，不随画布缩放变化
  - 图形自适应比例：分布荷载高度、集中力箭头长度、弯矩圆弧半径、内力图幅度随结构视图自动合理缩放
  - 自动视图适配与手动“一键适配”按钮
  - 视图模式：`model`、`moment`、`shear`、`axial`
  - 极值标注：在内力视图左上角显示当前模式全局 MAX/MIN

## 快速开始

要求：Node.js ≥ 18

```bash
npm install
npm run dev
# 生产构建与预览
npm run build
npm run preview
# 代码检查（如需）
npm run lint
```

开发服务器启动后，打开浏览器访问 `http://localhost:5173/`（若端口占用会自动切换）。

## 使用说明

- 左侧面板
  - 截面库：材料弹性模量 `E`、截面面积 `A`、惯性矩 `I`
  - 节点：坐标输入显示单位 `X (m)`、`Y (m)`
  - 单元：选择两节点与截面
  - 支座：固定端、铰、滚动支座（X/Y）
  - 荷载：节点荷载与单元荷载的添加与编辑

- 单位约定
  - 力：`kN`
  - 弯矩：`kN·m`
  - 分布力：`kN/m`
  - 长度：`m`

- 交互
  - 右键拖拽：平移（PAN）
  - 鼠标滚轮：缩放（ZOOM）
  - “适应屏幕”按钮：一键居中与合适比例
  - 顶部模式切换：`model`/`moment`/`shear`/`axial`
  - 结果面板显示：最大位移、自由度数等

## 数据导入/导出

右上角 “JSON DATA” 按钮可打开数据中心进行导入/导出。数据结构示例：

```json
{
  "sections": [{ "id": 1, "name": "混凝土梁", "E": 30000000, "A": 0.12, "I": 0.004 }],
  "nodes": [{ "id": 1, "x": 0, "y": 0 }, { "id": 2, "x": 6, "y": 0 }],
  "elements": [{ "id": 1, "n1": 1, "n2": 2, "sectionId": 1 }],
  "supports": [{ "nodeId": 2, "type": "fixed" }],
  "nodalLoads": [{ "nodeId": 1, "fx": 0, "fy": -10, "m": 0 }],
  "elementLoads": [{ "id": 1, "elementId": 1, "type": "uniform", "val1": 5 }]
}
```

## 代码结构

- 核心文件：`src/App.jsx`
  - 计算引擎对象：`SM_Engine`（局部刚度矩阵、求解器、FEF 计算）
    - 等效节点力计算：`SM_Engine.calcFEF(...)`
  - 数据状态：`sections`、`nodes`、`elements`、`supports`、`nodalLoads`、`elementLoads`
  - 求解流程：组装全局刚度矩阵与载荷向量 → 约束处理 → 线性方程求解 → 单元内力提取
  - 画布渲染：高清 Canvas、视图模式切换、荷载与内力可视化
